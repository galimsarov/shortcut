### 8 марта — Сумма транзакций по категориям за последний месяц (streams)
**Задача:** дан список транзакций `Transaction` с полями `String category`, `BigDecimal amount`, `LocalDateTime date`.  
Необходимо написать метод, который вернет `Map`, где ключ — категория, а значение — сумма всех транзакций в этой категории за последний месяц (относительно текущей даты).  
В результирующую мапу должны попасть только те категории, сумма транзакций в которых превышает заданный порог (например, `5000`).

```java
public class Transaction {
    private String category;
    private BigDecimal amount;
    private LocalDateTime date;

    // Конструктор, геттеры, сеттеры, toString
}
```

**Пример данных:**  
Сегодня: `2026-01-20`  
Транзакции:
1. `"Продукты", 1500, 2026-01-10`
2. `"Рестораны", 3200, 2026-01-05`
3. `"Продукты", 2500, 2025-12-15`
4. `"Транспорт", 800, 2026-01-01`
5. `"Рестораны", 2500, 2026-01-18`
6. `"Продукты", 3000, 2026-01-19`

**5 примеров тестовых данных (сегодня: `2026-01-20`, порог: `5000`):**
1. Транзакции: `[("Продукты", 1500, 2026-01-10), ("Продукты", 3000, 2026-01-19), ("Рестораны", 2000, 2026-01-12)]` → результат: `{}`
2. Транзакции: `[("Рестораны", 3200, 2026-01-05), ("Рестораны", 2500, 2026-01-18), ("Транспорт", 800, 2026-01-01)]` → результат: `{"Рестораны": 5700}`
3. Транзакции: `[("Продукты", 2500, 2025-12-15), ("Продукты", 3000, 2026-01-19), ("Продукты", 2200, 2026-01-08)]` → результат: `{"Продукты": 5200}` (запись от `2025-12-15` вне окна последнего месяца)
4. Транзакции: `[("Здоровье", 2600, 2026-01-03), ("Здоровье", 2400, 2026-01-15), ("Здоровье", 1000, 2026-01-16)]` → результат: `{"Здоровье": 6000}`
5. Транзакции: `[("Подарки", 5000, 2026-01-11), ("Подарки", 100, 2025-12-19), ("Книги", 5100, 2026-01-09)]` → результат: `{"Книги": 5100}` (категория `"Подарки"` исключается, т.к. сумма `5000` не превышает порог)

4. **Универсальный трансформер списка (Function / лямбды)**
